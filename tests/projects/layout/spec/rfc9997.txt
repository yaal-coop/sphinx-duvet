1.  Introduction

   Clients use the server at https://example.com/ per Section 2 and
   Section 9.  Section 4 of [RFC9998] and Section 1 of RFC 9999 are
   other parts.  See [RFC9998], [RFC1234] and [OTHER] for more, but
   not [NOWHERE].

   Section 3 has figures.

1.1.  Terms

   Client
      A program that sends requests.

   Server  A program that answers requests.  The server MUST
      answer as in Section 2.

   Token  A secret value.

   Endpoint

      A path on the server.

1.1.1.  Details

   This section is too deep for the table of contents.

   The client MUST retry.

   The server MAY wait.  The client
   MUST retry.
